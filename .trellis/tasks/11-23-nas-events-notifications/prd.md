# S04 持久事件与可选通知

## Goal

让用户关闭网页后仍能看到重要失败和待处理事项，可选向一个可信Webhook发送有界通知。状态：planning；相对工作量：大。

## 依赖与入口

- 存储/已有任务事件只需S01；S03失败生产者依赖S03实际契约，S02账号事件可后接。事件基础不反向依赖生产者，避免循环。
- 现有入口：`internal/app/store.go`、`server.go`、`collection_runtime.go`、`collection_store.go`、`collection_external_store.go`、`collection_rss.go`；`web/src/App.vue`、`api.ts`、`types.ts`。
- 拟新增事件/outbox/通知网络与局部UI模块；不复用扫描/enrich任务来承载全部通知。
- [总路线](../11-23-nas-evolution-plan/roadmap.md)、[拟议契约](../11-23-nas-evolution-plan/info.md)、[可靠性研究](../11-23-nas-evolution-plan/research/reliability-implementation.md)。

## 范围与拟议契约

- 统一持久未读中心：获取/导入失败、人工核对、持续离线、既有磁盘不足事实、备份失败；不替代原业务任务/阶段历史。S10后补完整容量范围。
- 事件以故障episode稳定键去重，重复累计、恢复关闭、再次故障新建；有界保留（草案90天/10000条）及可见截断计数，不能无限保留未读。
- 拟议events/read、一个notification-channel配置/test、deliveries查询/显式retry。分页/批量/队列限额，密钥URL单向写入私密文件，DB仅private_ref。
- 投递绑定接纳时不可变通道修订/目标快照；稳定eventId、固定JSON，有限至少一次尝试，可能重复，不保证最终送达/exactly-once。
- HTTPS、默认禁用、固定网络策略：每次拨号校验DNS/目标、拒绝所有重定向、无环境代理；私网/loopback必须独立明确授权，metadata/link-local等危险地址始终拒绝。测试投递同策略。
- 草案并发1/单次10秒/最多6次和24小时，响应64KiB、载荷16KiB、有界退避和Retry-After；通知失败不递归通知自身。
- 关闭通道停止旧队列，再启用只接新事件；恢复备份后用可操作的CLI/配置保持通知关闭，核对后再启用。

## 小 PR 顺序

1. **S04.1 事件基础**：增量表、typed helper、业务事务内事件/跨资源对账、episode去重；先接已有失败/待确认。
2. **S04.2 未读中心**：有界API、状态/跳转/计数、失败与空态、重启保留；移动端不增加第六主导航。
3. **S04.3 安全Webhook/outbox**：私密修订快照、持久领取/重试/退出、固定网络客户端、fixture故障注入。
4. **S04.4 阈值与联调**：负责接入S03已交付的备份失败结果，完成持续故障/恢复、关闭/轮换/恢复政策；不要求S03为等待事件能力而保持未完成。一个真实可信接收端实际验证，未验证的产品格式不宣称支持。

## Acceptance Criteria

- [ ] 浏览器关闭时发生失败，重启仍有未读；同故障合并，恢复后再故障能重开，保留截断可见。
- [ ] 业务事实/事件写入的崩溃窗口和补记可重复验证；通知失败不会触发原外部写重发。
- [ ] 2xx/400/408/429/500/超时/大响应/30x/处理后丢响应覆盖；次数、deadline、稳定ID和重复提示准确。
- [ ] DNS重绑定、IPv4/IPv6危险地址、未授权私网/回环、代理变量/跳转均不能外送秘密。
- [ ] 变更目标后旧队列不发新目标；关闭立即停止接纳/外送，重启也保持disabled，旧项只能显式重试。
- [ ] 恢复备份不会默认批量重投；CLI/配置和操作文档能实操禁用出口。
- [ ] 秘密不在公共DTO/普通DB快照/日志/localStorage；Linux权限/Windows ACL分别验证。
- [ ] 退出等待投递/请求回收后才释放DB与锁；隔离API/浏览器/队列回归和已实现契约同步。

## 实施前准备（2026-11-23）

- S04.1只读研究已交回`research/event-core-design.md`，覆盖现有生产者接缝、两表及来源固定水位、有界保留、原子事务助手、安全DTO与验收矩阵。
- 研究不预占schema；正式实施前须读取S03实际交付、冻结单一首接来源和接口，再补`info.md`。当前仍为planning，未新增事件业务能力、API或通知，未运行行为测试。

## 失败与回退

禁用出口停止通知，持久事件仍可查看；不删除原业务状态。保留未知投递的重复风险说明；这项至少一次规则不能套用为下载/订阅的盲重试许可。数据库降级仍需匹配快照及私密目标材料。

## Out of Scope / Definition of Done

不做站内聊天、邮件/短信/多通道矩阵、任意HTTP脚本、不可丢失审计或新任意探测器。按父路线统一门禁，临时单测执行后删除、稳定集成脚本保留。
