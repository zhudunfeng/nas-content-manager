# S06 本地元数据、人工纠错与持久海报

## Goal

让已有NFO和本地海报能成为本库可管理的元数据，允许人工纠错并防止重扫覆盖；人工原始素材具备独立备份恢复能力。状态：planning；相对工作量：大。

## 依赖与入口

- 硬前置：S05作品关系。S06.3开放人工上传前必须完成S03用户资产清单/文件备份与恢复验证；只读解析可先行。
- 现有入口：`internal/app/jobs.go`、`media.go`、`cache.go`、`models.go`、`store.go`；作品域使用S05实际文件；前端作品详情和`web/src/types.ts`。
- 拟新增元数据解析/合并/资产模块，不能把不可重建原件保存在现有可清理cache。
- [总路线](../11-23-nas-evolution-plan/roadmap.md)、[拟议契约](../11-23-nas-evolution-plan/info.md)、[媒体研究](../11-23-nas-evolution-plan/research/media-implementation.md)。

## 范围与拟议契约

- 电影/剧集标题、简介、年份、海报；受限NFO读取、来源显示、字段级覆盖/锁定、刷新差异确认。
- 拟议来源值、人工覆盖、锁定与revision分开存储。人工编辑默认锁定；显式空值是有效覆盖；解除锁后先预览再接受来源新值。
- 拟议作品metadata读/写、refresh-preview/apply、海报上传/鉴权读取接口；沿用严格JSON、鉴权/同源、计划过期及冲突控制。
- NFO/海报候选均需媒体根、符号链接和下载/收集发布门禁。某个视频可读不代表同目录任意sidecar已发布。
- 拟议预算：NFO 1MiB/深度32/节点20000/字段64KiB；海报10MiB/40M像素。实施时据样本确认并写入代码契约，不能只写文档；XML不访问DTD/实体/URL，海报拒绝SVG/HTML。

## 小 PR 顺序

1. **S06.1 安全读取候选**：限定命名、来源版本、有界XML与栅格图解析，返回候选及错误；不直接覆盖现值。
2. **S06.2 合并和锁定**：来源值/人工值/显式空值、字段锁、diff预览/应用、来源与对象revision，补显式后台任务分派/取消/重启。
3. **S06.3 编辑和资产闭环**：详情编辑/锁标志、人工海报持久发布、缩略缓存失效；接入S03已交付的通用资产清单/采集/恢复能力，由本切片完成真实上传原件端到端恢复后才开放入口，不要求S03反向等待S06。

## Acceptance Criteria

- [ ] 合法/坏XML、超深/超量、外部实体与远程海报、越界软链、未发布sidecar、多候选歧义均有有界、可解释结果。
- [ ] 来源文本作为纯文本显示，不用v-html；无源路径/原文秘密日志，无任何源目录写入。
- [ ] 锁定标题、空简介和海报经重扫、外部刮削、重启仍保持；解锁只在确认差异后替换。
- [ ] 无变化重扫不重复写；旧revision、来源变化及过期计划拒绝；任务失败不影响原文件浏览。
- [ ] 作品多版本元数据归属明确，不把任一版本NFO静默覆盖整部作品。
- [ ] 海报原件持久资产与派生缓存分离；清缓存可重建；隔离恢复后原件和引用仍可用。
- [ ] 取消/崩溃不发布半成品；孤儿临时文件可按归属回收，不能回收有引用原件。
- [ ] 完成隔离API/迁移/恶意输入/浏览器验证与文档/spec更新，记录目标NAS待验项。

## 失败与回退

暂停元数据增强后继续文件名/技术封面回退；保留人工覆盖和原始资产，不能当缓存删除。来源不可读只标失效不清空人工值。跨版本降级使用完整配套快照，不用旧程序忽略新增schema。

## Out of Scope

新在线provider、远程URL海报、媒体目录写回、全类型元数据平台、自动修改外部MoviePilot、无确认的批量覆盖。

## Definition of Done

执行父路线统一PR门禁；以集成脚本保留稳定回归，新增临时单测执行后删除；用户资产的端到端恢复是上传功能的发布条件。
