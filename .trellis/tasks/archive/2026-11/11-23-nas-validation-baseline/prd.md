# S01 建立回归基线与目标 NAS 验收档案

## Goal

让后续任务有可重放的本机回归和真实设备验收记录，准确区分已测、阻塞与未测。本项不增加业务功能。状态：本机交付完成，真实 NAS 发布门禁待验；相对工作量：中。

## 依赖与入口

- 无前置任务；这是下一项可直接实施的任务。设备缺失不阻塞本机基线及档案模板完成，只阻止对应目标发布通过声明。
- 现有入口：`scripts/verify*.py`、`scripts/project_env.py`、`web/package.json`、`docs/verification.md`、`docs/collection.md`、`docs/windows.md`、`docs/components.md`。
- 拟新增：有界编排入口`scripts/verify_baseline.py`和结果清单；最终参数需实现时明确，不当作已存在命令。
- [总路线/首项执行卡](../11-23-nas-evolution-plan/roadmap.md)、[拟议契约](../11-23-nas-evolution-plan/info.md)、[可靠性研究及命令模板](../11-23-nas-evolution-plan/research/reliability-implementation.md)。

## Requirements

- 盘点每个已有脚本的真实参数/前置/副作用/超时/产物；复用而非重写全部验证。
- 每次运行独立`.runtime/verify/<运行编号>`，显式产物/端口/自有进程；越界、链接目录、重复目录拒绝，不能碰用户运行实例。
- 拟议run-manifest记录版本、修改状态、工具/平台、命令脱敏、退出码、开始/结束、断言结果与证据相对路径；结果为passed/failed/blocked/not_run，缺产物不记通过。
- 单独保存真实NAS验收档案：OS/架构、CPU/内存/盘/文件系统、UID/GID/ACL、挂载、Docker/Compose模式、镜像摘要、样本/浏览器；未知项照实标记。
- 实测协议固定真实大媒体起播/拖动/吞吐、并发扫描/下载、CPU/内存峰值、大库查询、重启/失联及隔离恢复；掉电类演练仅备份后的隔离副本。

## 小 PR 顺序

1. **S01.1 盘点与协议**：现有脚本矩阵、最小冒烟、按变更领域扩展组合、证据分类和目标档案模板。
2. **S01.2 有界编排**：按现有参数执行、捕获结果、独立目录/端口、只回收自有进程、汇总；缺依赖明确blocked。保留原脚本独立运行能力。
3. **S01.3 首次基线和目标轨道**：运行本机最小组合并记录；有目标设备才补实测，其他组合保留待验，不让设备等待冻结后续独立开发。

## 首次执行注意

所有命令经`python -B scripts/project_env.py -- ...`。先核对脚本`--help`再编排：`verify.py`需要先启动隔离主实例并传`--base-url/--root`，没有`--binary`；`verify_collection.py`需要主服务和worker二进制；桌面脚本只接受桌面产物。不得只列脚本名就假定能运行。

核心构建/静态检查可用现有go vet/test/build与web typecheck/build；领域验证按研究中的现有参数补齐。未生成或为空的单测套件不算行为覆盖。真实工具选项和真实组件均需显式环境，不由local套件默认启动。

## Acceptance Criteria

- [x] 可重复运行两次且结果可比较、目录/端口不冲突；没有写出仓库可控缓存/临时根。
- [x] 缺产物、占端口、子项失败/超时、越界软链均产出准确结果；退出后自有进程回收，用户进程不受影响。
- [x] 本机最小基线覆盖鉴权、五媒体、扫描/用户状态、数据库快照，领域脚本分别覆盖发布门禁与不确定外部动作；每项都有断言/证据而非只见exit 0。
- [x] 历史测试、本轮实际执行、fixture、真实工具、真实NAS分开；5GiB稀疏Range不能计入真实解码/吞吐成绩。
- [x] 真实设备档案和M1/M2/M3待验表存在；未知信息没有编造，待验责任/所需输入清楚。
- [x] 本机可完成部分与真实设备发布门禁明确拆分；未拿到设备时保留待验表且可以开始S02。

2026-11-23：两次实际 core 各52项；下载36项、外部工作流83项、发布边界83项；最终编排自检39项。清理/证据保存故障注入均正确为failed，target模板结构通过但真实M1–M3保持待验。详见 [实施记录](implementation.md)、[独立复核](research/quality-review.md) 和 [复盘](research/debug-retrospective.md)。

## 失败与回退

本项不迁移生产数据。编排失败只回收自己拥有的进程/临时对象，保留日志，不能杀占端口的未知实例。撤回编排入口后原脚本仍可用；不删除历史证据。

## Out of Scope / Definition of Done

不修复本轮未授权的新业务问题、不启动真实组件做隐式演练、不编辑旧任务。按父路线规则检查脚本/文档；新增临时单测执行后删除。S01文档完成不等于真实NAS全部验收通过，后者持续作为里程碑门禁。
