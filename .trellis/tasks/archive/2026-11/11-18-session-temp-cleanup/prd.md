# 固定会话临时文件清理脚本

## Goal

将本会话在 Windows C 盘产生的构建与浏览器测试缓存整理为固定、可审阅和可复用的 PowerShell 脚本，先预览并记录精确清单，再由用户显式执行。

## Requirements

- 固定入口 `scripts/clean-session-temp.ps1`，Windows PowerShell 5.1 与 PowerShell 7 可解析，默认仅预览，不删除。
- 预览生成仓库 `.runtime/session-temp-cleanup/` 下含格式版本号的 JSON 文件清单，默认文件名为 `manifest.json`；显式 `-Execute` 仅读取已生成的清单，不重新扩大范围。可用 `-ManifestPath` 指定该专用目录内的其他清单路径。
- 默认仅识别包含当前仓库绝对路径的 Node 编译缓存文件。Go 编译/依赖缓存必须分别显式选择，并说明会清理共享的可重建缓存；浏览器必须提供精确 `mcp-chrome-<hex>` profile 名称，不能选择整个浏览器或自动取最新目录。
- 可选 `-Since` 限制文件创建时间。当前已确认的会话开始边界为 2026-11-17 17:30 +08:00；四个目录与 139 个 Node 文件的原始清单保存在 `.runtime/password-policy/c-drive-*.json`。
- 只接受当前用户 C 盘已知缓存根，拒绝驱动器根、用户根、通用 Temp、其他浏览器 profile、清单越界/相对路径/未知种类/重解析点。扫描与执行都核对路径，执行前检查 Go 构建进程和指定测试浏览器是否使用目标；不得自动结束进程。
- 清单记录每个文件的绝对路径、长度、创建/修改时间及所属目标。执行逐文件复核，跳过新增或发生变化的文件，幂等处理已不存在文件；只清理清单内文件与已空的清单目录，不对全盘或整个 Temp 递归删除，不跟随链接。
- 输出中文预览、执行摘要和结果记录；方法/字段/参数均有中文说明和明确类型。不记录文件内容或凭据，不自动提权或更改策略。
- 本轮直接递归删除命令已被执行工具策略拒绝，故不通过替代实现执行真实 C 盘删除；完成实现、默认预览和隔离/模拟验证，交付用户手动执行命令，并如实说明现有缓存仍保留。
- 不改动现有应用业务和密码实现，不运行 Docker，不自动提交、归档；新增临时测试源执行后删除。

## Acceptance Criteria

- [x] 默认运行只生成清单，现有 C 盘文件不减少；预览含精确位置、文件数和大小。
- [x] 显式参数选择 Go 缓存及指定 profile；Node 仅选本项目标记文件。
- [x] `-Execute` 绑定已有清单，拒绝篡改目标、越界、重解析点和正在使用的目标，忽略变更与清单外文件。
- [x] 幂等、只删除空目录、错误/部分失败报告与真实删除字节语义有隔离或模拟验证。
- [x] PowerShell 语法、文档与 Trellis 上下文检查通过，新增临时测试源清理。

## Technical Approach

1. 用白名单目标与显式开关扫描并生成精确文件清单。
2. 执行时再次校验目标、文件元数据和进程；按清单逐项处理并记录结果。
3. 独立复核脚本及隔离验证，README 补充预览/执行两条命令与缓存重建影响。

## Out of Scope

- 不清理业务数据库、媒体、源代码、用户正常浏览器资料、其他项目 Node 缓存、系统日志或通用临时目录。
- 不提供任意路径递归删除、绕过权限/执行审批、主动停止应用或静默提权功能。
