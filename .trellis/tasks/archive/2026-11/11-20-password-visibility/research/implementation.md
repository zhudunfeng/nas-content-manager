# 密码显示切换实现记录

## 修改文件与行为

- `web/src/components/PasswordInput.vue`：新增共享掩码输入组件，以必填字符串 `v-model` 保留表单数据，`inheritAttrs: false` 将 `id`、校验、自动填充、提示关联及监听器转发至原生输入框。每个实例独立保存临时可见状态，默认隐藏；清空值时同步恢复隐藏，重新挂载自然恢复初始状态。
- `web/src/components/Icon.vue`：添加本地 `eye` 与 `eye-off` 线性 SVG 路径。
- `web/src/App.vue`：替换登录/初始化密码及确认密码字段；保留长度、自动填充、初始化提示关联和原验证逻辑。字段容器使用显式 `label for` / `input id`，按钮与标签并列，避免按钮名称混入输入框名称。
- `web/src/components/CollectionSourceDialog.vue`：替换外部 API 凭据字段，保留 required、禁用、自动填充及占位提示，同时将现有凭据提示通过 `aria-describedby` 关联至输入框。
- 独立复核补充 `:key="externalService"`：切换外部服务时重新挂载凭据框，即使旧值为空也重置为掩码；避免对相同空值再次赋值时不触发 watcher 的边界。

## 可访问性与样式

- `type=button` 按钮不触发表单提交，具有中文动作名称、原生标题提示和 `aria-pressed`，可使用原生键盘交互。
- disabled 同时作用于输入框及按钮；组件未增加业务请求、持久化或秘密/切换日志。
- 使用现有 `icon-button`、焦点规则与语义主题颜色。按钮尺寸为 44×44px，输入框右侧预留 56px，字段容器和输入框均允许收缩。
- 样式均在对应组件中 scoped，认证字段保留原有 9px 字段间距和 22px 底部间距。
- 截图复核后为创建账户密码规则增加相邻提示间距 `margin: -10px 0 22px`，输入框至提示为 12px，提示与确认密码标签保持 22px，避免多行提示末尾紧贴下一字段。
- 精确标签与按钮名称：`密码` / `显示密码`、`确认密码` / `显示确认密码`、`API Key / Token`（AutoBangumi 为 `API Token`）/ `显示API 凭据`；显示后动作名称对应变为“隐藏…”。
