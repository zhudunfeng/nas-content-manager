# NAS 内容管理系统功能缺口评估

## Goal

基于 2026-11-23 当前仓库，评估栖库已具备、部分具备和缺失的产品能力，形成有代码依据的优先级与迭代建议。本次交付为评估报告，不实施业务功能。

## 已知事实

- 用户要求评估当前系统还缺少什么功能，并指出 CodeGraph CLI 可用。
- 当前分支为 main，开始评估时工作区干净；基准提交为 `6f380be`。
- 当前活动任务 `11-20-collection-component-install` 处于 review，本评估单独建档，不修改其 PRD 和状态。
- 项目已有五类媒体库、原文件播放/阅读、BT 搜索下载、资源收集及四类固定外部组件部署与 API 集成。

## Requirements

- 优先使用已有 CodeGraph 索引检索，结合实际路由、数据模型、前端入口、配置和验证记录交叉核验。
- 区分完整闭环、部分实现、尚未实现、已有独立计划以及仅缺真实环境验收。
- 从媒体组织、播放阅读、资源获取、账户安全、数据恢复、运维与扩展评估功能缺口。
- 给出按用户价值和前置依赖排序的下一阶段范围与可验收结果。
- 所有结论持久化到本任务 research 与报告，最终回复提供关键依据。

## Acceptance Criteria

- [x] 已有能力得到代码核验，不将现有订阅、下载、备份、组件部署误判为缺失。
- [x] 主要缺口有路径、符号或准确行号依据，并明确已证实与推断边界。
- [x] 交付按优先级整理的功能矩阵和建议迭代顺序。
- [x] 仅新增本任务评估资料，不修改业务代码或既有任务。

## Definition of Done

- 研究资料与评估报告落盘，检查引用文件和结论一致。
- 本次没有业务代码变更，无需运行完整构建；不生成单元测试。
- 无真实 NAS、真实外部组件和浏览器运行验收时明确说明限制。

## Out of Scope

- 实施新功能、修复代码、安装组件、启动业务实例、变更用户媒体和外部服务。
- 未经请求比较外部产品当前版本或将建议视为已获实施授权。
