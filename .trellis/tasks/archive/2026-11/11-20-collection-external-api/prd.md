# 外部自动化服务深度 API 控制

## Goal

2026-11-20 用户要求继续推进 MoviePilot、AutoBangumi、Sonarr/Radarr 的深度API控制。保留已实现的公开外部入口和独立完成目录只读导入，新增固定、类型化、按真实能力开放的API适配器和管理界面。

## 已知事实与授权

- 父任务资源收集已实现external来源、公开应用入口、独立成品目录登记；原契约把深度API管理列为后续，本次用户指令将其纳入实施范围。
- 当前工作树包含上轮尚未提交的完整实现，不能重建、回退或覆盖无关修改。
- 不连接用户真实账号、不操作真实外部订阅或媒体，不安装部署第三方套件；使用官方协议核实及隔离服务验证。
- 遵守AGENTS中文注释/日志、显式类型和项目环境包装器；新增临时单元测试执行后清理，保留可复用集成脚本。

## Requirements

- 简单易用是硬性验收条件：选服务→填地址和凭据→检测连接；自动判断支持版本，普通流程不要求理解API版本或底层参数。日常订阅与任务集中呈现，高级配置折叠、中文错误可操作，离线与空列表明确区分。
- 用户补充硬范围：MoviePilot 的集成搜索、订阅、下载编排、整理、刮削和媒体库刷新必须全部提供本系统内可操作的集成；不能只给外部链接。搜索结果经确认后提交下载，整理/刮削/刷新明确作用范围与执行结果，使用官方固定业务API而非任意命令。
- 明确说明由外部服务负责获取，文件进入专用完成目录后仍需本系统预览并扫描登记；避免重复入口、术语堆积或打开页面即搜索、安装、创建订阅。
- 保留external来源的入口和独立目录导入，新增服务类型和私密连接配置；凭据只写不回显，不混入普通DB备份、日志或公开DTO。
- 固定支持MoviePilot、AutoBangumi、Sonarr、Radarr；按官方实际API和可核验版本声明能力，不使用任意URL/方法/body透传。
- 覆盖连接/版本/健康、资源/订阅列表、队列/历史，以及各服务可明确映射的新增订阅、启停或监控、显式搜索动作。跨服务差异通过能力显示，不能返回假成功。
- 状态读取有界、鉴权、同源；实例私网访问必须显式授权，连接/重定向/错误输出沿用来源安全边界。
- 修改动作绑定来源revision、稳定请求ID、固定动作与目标，持久化结果；响应不确定时先对账，不能因超时盲目重复创建或全局搜索。
- 外部套件继续作为其任务唯一编排方；本系统观察或明确调用它的业务API，不接管qB、不混用内部自动订阅、不把队列完成等同于本系统扫描入库。
- 管理界面提供独立检测、状态/列表错误、支持动作和确认；完成目录通过现有预览/登记链路导入。

## Acceptance Criteria

- [x] 接入流程不超过三个主要步骤；日常管理和完成目录导入入口明确，高级配置按需展开，桌面和手机均可用。
- [x] MoviePilot 六项业务能力全部实现并通过协议与界面验证；有副作用的操作明确确认、固定目标且提交结果不确定时不盲重发。
- [x] 官方API、认证、版本差异、动作边界和支持矩阵落盘，未确认能力默认禁用。
- [x] 四类固定适配器的真实HTTP协议fixture验证通过，认证和响应映射正确。
- [x] 写操作具备持久幂等、revision和结果不确定处理，不能重复创建外部任务。
- [x] 密钥/令牌与私有端点不泄漏；越界路径、重定向及未授权私网拒绝。
- [x] 前端外部来源配置和控制界面可用，原external只读导入及已有收集回归通过。
- [x] Go vet、构建、类型检查、真实浏览器和适配器集成验证通过，临时新增单测清理；记录未覆盖真实实例条件。

## Technical Approach

先研究官方源码/OpenAPI和仓库扩展点，随后形成可执行API契约。预期在internal/app扩展固定客户端、来源秘密及动作记录；复用资源收集会话/目录/入库，不新增任意执行协议。数据迁移以当前schema v3为基础增量推进，不能冲突或覆盖历史。

## Out of Scope

任意HTTP代理、任意命令/插件安装、Docker远程部署、全局下载器/站点配置写入、删除媒体文件、自动接管现有qB任务、批量破坏性操作。真实外部实例操作留待用户配置后单独验收。
