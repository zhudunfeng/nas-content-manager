## 状态与目标

本文件保留方案阶段的视觉方向。2026-11-17 已以 Vue 3 实现“栖库 · QIKU”首版并完成浏览器渲染检查：首页、四类内容网格、详情、媒体库、任务、设置、独立播放器与阅读器。明暗主题和 375/768/1024/1440 像素宽度已检查；移动漫画工具栏调整为分行控件。实际范围以 README 与 docs/verification.md 为准，下文未在首版提供的时间线、系列聚合、书签、转码状态等仍是后续方向。

目标是像一个日常使用的个人媒体库：内容封面清楚、操作直接、继续观看/阅读方便。采用统一视觉语言，并按四类内容选择适合的呈现方式。

## 视觉方向

- 风格：克制、清晰、封面主导。减少装饰，让内容缩略图与文字层级形成页面重点。
- 主题：提供明暗主题，默认跟随系统，允许用户固定选择。小说阅读器另外提供护眼纸色。
- 暗色建议：石墨底色 `#111418`、卡片 `#1B2026`、主文字 `#F3F4F6`、强调色 `#5EEAD4`。
- 亮色建议：背景 `#F5F6F8`、卡片 `#FFFFFF`、主文字 `#1F2937`、强调色 `#0F766E`。
- 颜色通过语义变量管理，组件不散布任意颜色；色值仍需在真实按钮、文字、焦点和状态组合中验证对比度。
- 字体：中文优先使用本地系统字体，正文建议 16px、行高约 1.5；避免为视觉效果强制下载公网字体。
- 图标：统一线性 SVG 图标并随应用发布；图标按钮提供可读名称与提示。
- 卡片：圆角、留白与边框统一；封面避免强烈阴影和永久大面积玻璃模糊。
- 动效：短暂淡入、轻微位移与可感知反馈；支持减少动态效果设置，不依赖复杂动效完成操作。

## 导航与首页

桌面使用左侧导航、顶部搜索和内容区域。主要导航为：首页、视频、图片、漫画、小说；收藏和管理设置放在次级位置。

手机底部最多放首页与四类内容五个主入口，搜索、收藏与设置通过顶部或用户菜单进入。阅读和播放全屏时收起导航，退出后返回原列表位置。

首页内容按使用频率排列：

1. 继续观看/继续阅读，明确显示进度与最近时间。
2. 最近添加，可筛选四类内容。
3. 最近访问的媒体库与收藏。
4. 扫描任务使用轻量状态入口，错误时给出可行动提示。

首页不默认堆叠系统统计卡片。硬盘容量、处理任务详情和管理配置集中在设置与任务面板。

## 四类内容页面

| 内容 | 列表与详情 | 消费界面 |
| --- | --- | --- |
| 视频 | 封面海报墙，支持电影竖海报与横向视频缩略图；片名、时长、进度层级明确 | 播放器按需显示控制栏，支持续播和清晰错误提示 |
| 图片 | 文件夹/相册与时间线切换，预先记录尺寸减少布局跳动；支持网格密度调整 | 大图灯箱、缩放、前后切换，元数据默认折叠 |
| 漫画 | 独立系列书架，详情列出卷/章节、阅读状态与继续阅读入口 | 单页、双页、连续滚动；左右阅读方向；章节/页码定位与进度恢复 |
| 小说 | 封面书架/信息列表切换，作者、章节、格式和进度清楚 | 目录抽屉、字号、行距、主题、书签和沉浸阅读，优先保持文本可读 |

漫画不是图片相册的换皮页面；系列、卷/章节、页序和进度需要独立设计。小说也不共用漫画图片阅读器。

## 易用性细节

- 首次使用向导控制在创建管理员、选择已挂载目录、确认扫描几个步骤；高级参数后置。
- 全局搜索支持按类型筛选，保留最近使用的筛选项，返回列表后不丢滚动位置。
- 不支持的格式明确标注原因和处理建议，避免用户反复点击无响应。
- 扫描中可以浏览已发现的内容，任务进度与失败原因可见。
- 封面缺失时使用统一占位封面并显示标题，避免破坏卡片排布。
- 空库引导添加目录，离线库提供重新检查，权限错误提示检查挂载和目录权限。
- 操作成功、失败、加载和取消均有反馈；非必要操作不弹出重复确认。
- 超大视频单独设计准备、缓冲、转换、失败和继续播放状态；连续拖动合并请求，退出后取消无用工作，恢复到保存进度。高级播放信息可查看，但不以未经验证的判断误报网络或硬盘故障。
- 外部内容标题、EPUB 页面与漫画归档内容不能注入脚本或改变全局样式。

## 资源与部署约束

- 前端、字体和图标随应用发布，基础使用不依赖外部 CDN。
- 缩略图异步生成并按需加载，长列表采用分页或虚拟化；不一次性加载整库原图或所有漫画页。
- 大量阴影、模糊与持续动画不作为默认视觉手段，兼顾低性能移动设备。
- UI 设计不增加新的独立服务；前端产物仍内嵌单应用镜像。

## 建议实施顺序

先制作首页、一个内容书架、漫画阅读器与首次使用向导的视觉稿，验证统一设计是否兼顾展示、阅读与配置。确定后再扩展其余页面，避免功能完成后重新调整整体界面。此步骤为后续实施建议，本轮没有生成前端代码。
