# S02 账号页与浏览器验收准备

日期：2026-11-23。这是S02.2的局部交互约定，不代表UI已实现。复用当前Vue设置页和PasswordInput，不改变原有导航或视觉系统。

## 复用与布局

- 当前 `App.vue` 的 `settings-layout` 在桌面为两列，窄屏为一列；`settings-panel` 已有边框、背景、内边距与主题变量。账号安全组件作为同级section加入，不套新整页或布局表格。
- 组件显示“修改密码”和“登录会话”；当前密码、新密码、确认新密码有独立label/id，提示与错误关联。复用PasswordInput的独立默认掩码、44px显示按钮和原字符串透传。
- 新密码和确认密码使用new-password自动填充，原密码/撤销其他会话再认证使用current-password；允许密码管理器和粘贴。原密码不套新复杂度规则。
- 会话列出安全类别、创建时间未知/过期时间和“当前设备”标记；当前标记来自API。撤销当前明确说明将退出；其他会话撤销和刷新/分页有独立忙碌状态。
- 修改密码成功明确提示重新登录，复用现有全局session-expired清理；错误不泄露敏感值。离开设置、请求完成及组件卸载清空密码，卸载取消读请求并防止迟到响应回写。

## 已核验的技能建议

已读ui-ux-pro-max，按目标组件搜索：`accessible authentication --domain ux -n 3`。首项为Security / Accessibility的Accessible Authentication，确认适用于密码表单；本任务采用允许粘贴、密码管理器与current-password自动填充的建议。其passkeys/OAuth建议超出单管理员范围，不扩展本任务。

浏览器自动化技能已读；它引用的 `../tool-index.md` 在本机技能目录缺失，使用当前真实工具清单及本项目现有Playwright集成脚本核实能力，不猜工具路径、不因此安装全局依赖。浏览器和fixture启动必须经project_env继承项目环境；已启动MCP进程不能补称获得隔离环境。

## 浏览器验收切片

1. 隔离真实后端新目录/账号，验证现有设置能进入账号组件、初始会话和独立密码掩码。
2. 弱/中文新密码与不一致确认在前端阻断且无POST；合法新密码发送原值；错误原密码显示服务端错误且保持登录，提交后表单清空。
3. 两浏览器context产生两个实际会话，列表/刷新/分页/撤销其他、撤销当前和改密后旧Cookie失效均由实际API验证。受控错误/空/迟到响应另标为UI呈现证据，不能与真实后端行为混淆。
4. 键盘Tab/Space/Enter和显示按钮不误提交；必要确认对话框Escape/焦点恢复。375/768/1024/1440×明暗检查无横向溢出、输入/按钮可达并保存截图，目视检查变化区域。
5. 检查无pageerror；日志、DTO、localStorage不含密码/token/hash/原UA。截图前清空秘密。关闭自有浏览器和fixture，保留安全结果摘要与受限本地材料的区别。

稳定集成脚本可保留；新生成的临时单元测试源码在完成运行后删除。最终计数与证据路径由实际执行后记录，不提前填写。
