# 管理员密码复杂度规则

## Goal

将新建管理员密码规则调整为仅允许英文字母、数字和英文标点，同时包含大写字母、小写字母、数字和特殊字符，禁止中文；前后端一致，并提供清晰中文提示。

## Requirements

- 沿用现有 10–72 个 UTF-8 字节长度范围，不更改密码哈希算法或数据库结构。
- 四类字符分别为 ASCII `A–Z`、`a–z`、`0–9` 和可打印 ASCII 标点（例如 `!@#$%`）。按用户追加要求禁止中文，新密码只允许这四类字符（U+0021–U+007E），不允许中文、全角字符、空格、控制字符或表情；非法输入直接拒绝，不 trim、不截断。该字符范围内字符数与 UTF-8 字节数相同。
- 后端 `/api/setup` 为最终校验边界，长度/复杂度不符合返回 400 与中文错误，且不创建账户。
- 首次创建账户表单同步校验、更新密码提示，保持确认密码检查；登录不套用新复杂度要求，存量账户按原密码正常登录。
- 当前无修改密码接口；本任务不增加改密/重置密码流程。
- 现有验证脚本自动生成的应用管理员密码保证满足四类要求；不更改无关 BT 引擎凭据策略。
- 按项目约定保留中文方法/字段注释和关键逻辑说明，日志不记录密码或密码片段。

## Acceptance Criteria

- [x] 缺少任意一类字符、长度不符或包含非允许字符均被拒绝，合法四类与长度范围的新密码可创建账户。
- [x] 9/10/72/73 字节、中文含扩展汉字、全角字符、空格、控制字符、表情、特殊字符边界有验证。
- [x] 前后端使用相同输入矩阵，存量较弱/含中文密码仍可登录，错误密码仍失败。
- [x] 既有验证脚本生成的管理员密码不因规则升级随机失败。
- [x] Go 格式/静态检查/测试/编译与 Vue 严格类型检查/构建通过，执行后删除新增临时单元测试源。

## Technical Approach

1. 定义并实现后端新密码校验，保留登录密码匹配行为。
2. 更新前端新建账户校验、可访问中文说明和已有验证凭据生成。
3. 用隔离数据与实际 HTTP 验证规则/旧账户兼容性，核对前后端一致性；更新 API/规范及执行记录。

## Out of Scope

- 不修改已有密码、迁移账户、强制用户重设密码或增加修改密码 API。
- 不执行 Docker 部署，不调整密码哈希算法，不自动提交或归档。

## Technical Notes

- 后端 `internal/app/auth.go`：首轮已新增四类与字节长度规则，本次收紧字符白名单；login 继续只校验原哈希并拒绝超过 72 字节。
- 前端 `web/src/App.vue`：创建/登录共用 authenticate，必须仅在 setupRequired 时应用新复杂度。
- 首轮已用固定四类前缀与 `secrets.token_urlsafe` 后缀生成脚本密码，天然符合本次 ASCII 白名单，无需再次修改无关脚本。
- 遵循 `.trellis/spec/backend/runtime-contract.md`、`.trellis/spec/frontend/app-contract.md` 与项目 AGENTS.md。
